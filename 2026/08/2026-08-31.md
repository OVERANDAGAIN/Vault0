

# Summary
This paper investigates whether the next user event in open-domain human–LLM conversations can be predicted using only content-free structural dynamics. The authors formulate a four-class next-turn event prediction task with Continuation, Repair, Abandonment, and Gratitude, and represent each conversation prefix using 45 structural features covering turn structure, user and assistant length trajectories, length-ratio trajectories, and punctuation statistics. An XGBoost classifier is evaluated on 211,202 prefix–next-event pairs derived from 37,227 multi-turn WildChat conversations.

The dynamics model achieves a macro-AUC of 0.744, outperforming the TF-IDF and SBERT content baselines at 0.682 and 0.666. The largest gain is on Abandonment, where dynamics reaches 0.836 AUC compared with 0.631 for TF-IDF; a fully fine-tuned full-prefix DeBERTa-v3-small still remains below dynamics on this class. The paper further evaluates the result through position and length controls, out-of-slice replication, cross-platform experiments on LMSYS-Chat-1M, and a lexicon-free final-turn control. The main conclusion is that conversation structure provides an independent ranking signal for imminent session ending.
