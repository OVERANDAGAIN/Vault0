# 消费者Buyer
| 设计环节       | 具体规则                                                                |
| ---------- | ------------------------------------------------------------------- |
| **用户设定**   | 设置价格优先、偏好明确、谨慎比较、急用省事四类用户。<br>每人有多个兴趣，以及必须满足的条件和更喜欢的特征。个人设定生成后保持稳定。 |
| **开始购物**   | 随机安排购物时间，允许多人同时开始。                                                  |
| **考虑范围**   | 每次从个人兴趣中抽取几个关注方向。<br>商家推荐的其他商品，只要符合其长期兴趣，也可以加入比较。不预先指定必买商品。         |
| **购买条件**   | 商品在可接受范围内，必要规格符合，报价不超过接受上限，当前余额和库存足够。                               |
| **选择与购买**  | 用户类型决定选哪款、比较多久。完成比较后，从合格商品中选择并提交购买，不再额外随机决定“买不买”。                   |
| **没有合格商品** | 说清具体原因，例如规格不符、报价偏高、资金不足或缺货。等待商品、报价、信息或资金变化后重新判断。规则确定原因，LLM 负责自然表达。  |
| **成交与结束**  | 购买成功后，更新余额、已购物品和需求记录。购买失败则重新判断，待确认时不重复下单。期限结束仍没有合格选项，才记为未成交。        |
