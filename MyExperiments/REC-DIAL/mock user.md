第一组，直接搜 LLM 用户模拟：

A Survey on LLM-based Conversational User Simulation。这是 2026 年的综述，比较适合作为总入口，因为它专门把 LLM-based conversational user simulation 的 granularity、simulation objectives、core techniques 和 evaluation methodologies 做了 taxonomy。



第三组，搜 conversational recommender，因为你的系统里有推荐/广告成分：

conversational recommender system user simulator LLM
LLM user simulator conversational recommendation feedback
realistic user simulator CRS LLM
rating action response user simulator
bounded rationality user simulator LLM

这会搜到 Evaluating Large Language Models as Generative User Simulators for Conversational Recommendation。这篇很重要，因为它不是只提出一个 simulator，而是提出了评估协议，测试 synthetic user 是否能做到：选择谈论的物品、表达二元偏好、表达开放式偏好、请求推荐、给出反馈。它也指出 baseline simulator 会偏离真实人类行为
