````ad-info
## 1. CLI 增加新参数

新增参数：

```bash
--user-simulator profile
--user-simulator llm
```

默认值是：

```text
profile
```

所以原来的实验不会变。

原来的：

```bash
--user-response corpus
--user-response hybrid
--user-response llm
```

仍然保留，但它现在只控制 `ProfileSimulator` 内部的 response generator。

当你使用：

```bash
--user-simulator llm
```

时，`--user-response` 实际上只是保留在配置和 run_id 里，不再决定 user 行为。

````
