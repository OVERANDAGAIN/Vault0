## 总表字段 / 体验时注意检查的

1. **概览**
	1. 使用形态
	      1. 开发机器 / 工作空间
	      2. 后台任务
	      3. 一段函数 / Serverless
	      4. API / 已有能力调用
	      5. 专用任务，如渲染
	2. 交付什么
	      1. 机器
	      2. 开发环境
	      3. 任务执行
	      4. API 返回
	      5. 最终结果
	3. 使用入口
	      1. 网页
	      2. CLI
	      3. IDE / 本地客户端
	      4. 插件
	      5. API / SDK
2. **开始使用门槛**
	1. 注册 / 登录
	2. 是否绑定其他账号
	3. 是否需要充值
	4. 是否实名
	5. 是否需要申请权限 / API Key / 授权
3. **项目接入**
	1. 源代码 / 工程如何上传
		  1. 手动上传
		  2. Git
	      3. 自动同步
	      4. 插件打包上传
	      5. API 参数
	2. 数据 / 模型 / 素材如何上传
	3. 子目录和额外文件是否自动处理
	4. 路径依赖怎么处理
		  1. 本地绝对路径
	      2. 外部文件
	      3. 挂载目录
	      4. 共享存储
	5. 工程需要改多少
		  1. 基本不用改
	      2. 补配置
	      3. 改入口 / 路径
	      4. 改代码
	      5. 重新封装成镜像 / API
	6. 提交前有没有检查
	      1. 缺文件
	      2. 路径错误
	      3. 入口错误
	      4. 环境不兼容
4. **GPU / 资源与环境**
	1. GPU 怎么选择
		  1. 用户选具体 GPU
	      2. 用户选规格
	      3. 用户只提需求
	      4. 平台自动匹配
	2. 单卡 / 多卡如何选择
	3. 没有合适资源怎么办
	      1. 用户重新选
	      2. 排队
	      3. 自动换节点
	4. 镜像如何选择
	      1. 官方镜像
	      2. 自定义镜像
	      3. 自动构建
	5. CUDA / 驱动 / 框架版本是否检查
	6. 环境是否与项目自动匹配
	7. 缺依赖 / 配置问题谁处理
	      1. 用户
	      2. 平台提示、用户处理
	      3. 平台自动处理
5. **执行与报错**
	1. 怎么开始执行
	      1. SSH 后自己运行
	      2. 提交命令
	      3. 提交任务
	      4. 调用函数 / API
	      5. 插件提交
	2. 是否生成任务编号 / Job
	3. 实时状态
	      1. 排队
	      2. 准备资源
	      3. 准备环境
	      4. 正在执行
	      5. 上传 / 处理结果
	      6. 完成
	4. 是否能看日志
	5. 是否能确认真正使用了目标 GPU
	6. 关闭网页 / IDE / 客户端之后
	      1. 任务停止
	      2. 已提交任务继续
	      3. 整条流程继续
	      4. 仍依赖本地某些组件
	7. 报错是否能说明原因
	      1. 资源问题
	      2. 环境问题
	      3. 代码问题
	      4. 节点问题
	      5. 查询 / 状态问题
	      6. 文件传输问题
	8. 报错后怎么办
	      1. 全部重跑
	      2. Retry
	      3. 局部重算 / 补算
	      4. Checkpoint 继续
	      5. 只重新上传 / 下载
	      6. 平台自动重新调度
6. **结果**
	1. 程序输出后是否自动识别为结果
	2. 结果保存在哪里
	      1. 当前机器
	      2. Volume / 共享存储
	      3. 对象存储
	      4. 平台任务结果
	      5. 本地
	3. 是否需要另开持久化存储
	4. 怎么拿回结果
	      1. 自己找路径
	      2. SCP / 文件同步
	      3. 网页下载
	      4. 自动回传
	      5. API 返回
	5. 是否还需要额外处理
		  1. 拼接
	      2. 合成
	      3. 打包
	      4. 转码
	6. 谁确认结果完整、可用
	      1. 用户自己
	      2. 平台提供辅助检查
	      3. 平台自动检查
	7. 停止任务 / 关闭机器之后结果还在不在
	8. 结果能保留多久
7. **再跑一次**
	1. 原来的资源配置能否复用
	2. 镜像 / 环境能否复用
	3. 代码是否需要重新上传
	4. 数据 / 素材是否需要重新上传
	5. 任务参数是否保留
	6. 已有结果是否能够复用
	7. 已完成部分能否跳过
	8. 第二次运行还需要重复哪些操作
8. **停止与费用**
	1. 什么动作真正停止计算
	      1. Stop
	      2. Shutdown
	      3. Release
	      4. Terminate / Delete
	2. 关闭网页 / 客户端是否影响计费
	3. 任务完成后是否自动停止计算
	4. 停止计算后是否仍有费用
	      1. 磁盘
	      2. Volume
	      3. 公网 IP
	      4. 其他存储 / 服务
	5. 是否能明确看到已经停止计费
	6. 是否有限时 / 预算 / 自动停止机制
